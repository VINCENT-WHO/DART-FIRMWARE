# 绿灯EKF状态估计

适用固件 `2.4.0-green-ekf`，基于main的ROI稳定版。按提供的引导灯预测算法实现，输入为检测质心及绿色连通域像素面积。模型假设目标静止、飞镖接近时像素速度随距离倒数增大；只做状态估计和记录，不改变RGB检测、ROI或原始检测标注。

## 状态、时间与标定

状态顺序为 `[x, y, vx, vy, s, ds]`。位置单位像素，速度单位像素/秒，`ds`为`s`每秒变化量。实际帧间隔由相机帧完成时间差计算，使用秒单位，不把丢帧后相邻处理帧误当成固定间隔。

`A=K*s²`，`s=1/r`。默认 `GREEN_FILTER_CALIBRATED_K=0` 表示未标定：第一次有效观测令 `K=A0, s=1`，于是 `s`表示相对初始距离的倒数比例，不能标成1/m。需要绝对距离时，在已知距离r米处测量同一目标的绿色像素面积A，设置 `K=A*r²`；否则单凭像素面积不能恢复绝对米制距离。

每次重新初始化都记录当前K，未标定模式下会重新建立参考面积。相机曝光、颜色阈值、目标姿态、遮挡和ROI裁边都会改变面积，模型并不能自动区分这些变化和真实距离变化。

## 预测与更新

对上一状态，使用真实间隔 `dt`：

```
x'  = x + vx*dt
y'  = y + vy*dt
vx' = vx*(1 + ds/s*dt)
vy' = vy*(1 + ds/s*dt)
s'  = s + ds*dt
ds' = ds
```

状态雅可比除单位/位置速度项外：`F(vx,vx)=F(vy,vy)=1+ds/s*dt`，`F(vx,s)=-vx*ds/s²*dt`，`F(vx,ds)=vx/s*dt`，y方向同理，`F(s,ds)=dt`。先计算 `P'=F*P*Fᵀ+Q`。

观测预测 `h=[x', y', K*s'²]`。H的位置项为1，面积项 `H(A,s)=2*K*s'`。按图中形式使用自适应观测噪声：

```
R = diag(σx², σy², σA²/s'²)
S = H*P'*Hᵀ + R
gain = P'*Hᵀ*S⁻¹
```

实现通过3×3 Cholesky求解方程而不显式求逆，协方差采用Joseph形式 `P=(I-gain*H)P'(I-gain*H)ᵀ+gain*R*gainᵀ`，降低单精度舍入导致的非正定风险。

默认调参值（均为合成验证初值，未由实拍标定）：σx=σy=2像素，σA=20像素面积单位；过程噪声 `Q=diag(1,1,400,400,0.0025,0.25)*dt`；初始P对角为 `[4,4,2500,2500,0.01,1]`。位置/面积测量初始化，速度和ds初始化为0。

## 失效与异常处理

- 未检出、NaN、非正面积或越界质心视作无有效观测；初始化之前不输出虚构状态。
- 短时无观测只做预测，不伪装成测量更新。
- 新息归一化平方距离 `NIS=residualᵀ*S⁻¹*residual` 超过25则拒绝此次观测，保留预测状态。
- 连续超过0.5秒没有接受观测，或相邻帧间隔大于0.25秒，放弃旧状态；当前有有效观测则重建，否则失效等待。
- 相同或逆序时间戳不推进状态；32位微秒正常回绕通过无符号差值处理。
- s必须在0.001～1000之间；非有限状态、异常协方差或分解失败会重置。有效当前观测可重新初始化，状态码明确记录。

状态码：0等待首次观测；1初始化；2测量更新；3仅预测；4观测拒绝；5长时间丢失；6间隔/丢失后重建；7时间无效、状态未推进；8数值异常重置（看estimate_valid判断是否已重建）。

## FILTER.CSV字段

CSV用UTF-8 BOM，列名英文含单位；`s`及其变化量的物理单位由K是否标定决定。无测量/无估计时相应字段留空，不用0坐标冒充目标。初始化或重建帧的pred字段等于初始化值，不代表一次动态预测；NIS未计算时留空。

- `attempt,avi_frame,capture_us,dt_us,status,measurement_valid,estimate_valid,filter_us`：处理序号、保存成功的AVI帧号、相对触发时间、帧间隔、状态及微秒耗时。编码或保存失败时AVI帧号留空。
- `measured_x_px,measured_y_px,measured_area_px`：原始检测观测。
- `pred_x_px,pred_y_px,pred_vx_px_s,pred_vy_px_s,pred_s,pred_ds_s`：本次校正前状态。
- `x_px,y_px,vx_px_s,vy_px_s,s,ds_s,K_area_scale,NIS`：校正后状态、面积标定比例及新息门限量。
- `var_x,var_y,var_vx,var_vy,var_s,var_ds`：估计协方差对角，各自状态单位的平方。

CSV格式化在采集结束后进行；整数格式化浮点数据到6位小数，避免依赖newlib-nano未启用的浮点printf。预测与测量均对应当前采集时刻，不包含任意未来时刻的瞄准指令。

自动会话路径为 `REC#####/FILTER.CSV`（FAT不区分大小写，即filter.csv）；手动命名会话为 `Dxxxxxx.FLT`，遵循现有8.3命名以避免不同会话覆盖。编码或AVI写入失败的处理帧仍有滤波记录，AVI帧号留空。若只是后续DETECT文本写入失败而AVI帧已经成功追加，仍保留对应AVI帧号。

滤波明细单条120字节，最多600条，占72000字节，加汇总头共72064字节，放AXI SRAM。每次准备会话先重置估计器和明细计数；超过容量保留原600行、继续统计总次数/耗时和丢弃数，不覆盖旧行。TIMING与FILTER按同一处理序号对应，包含无目标和失败帧。

`TIMING.CSV` 末尾新增 `EKF估计_us`（原25列保持位置，总26列），与FILTER的 `filter_us` 相同。总处理时间包含这段计算，检测和绘图时间不重复包含；RAM追加开销沿用现有周期计数记录，文件导出单独计时。`INFO.TXT` 给出平均/最大估计耗时、状态次数、明细丢弃数、导出耗时及失败标志。

FILTER导出发生在录像及原日志关闭后，创建新文件，不覆盖已有文件；写入/关闭失败使会话最终状态标记失败。首次没有目标时仍输出带状态的空估计行。

## 验证

`tests/test_green_filter.c` 使用合成数据检查雅可比、协方差正定、可变时间间隔、位置平滑、丢失/异常跳点/回绕/重建和CSV边界。

`tests/verify_green_filter.py` 用独立float64 NumPy矩阵公式对照生产C单精度实现，覆盖相对K和已标定K。所有结果都不是板端计时、真实距离精度或实拍检出率验收；不使用旧曝光录像调参。
